# PHP Webmaster Toolkit

A lightweight collection of essential utility scripts and security configurations for webmasters and independent developers.

## Included Tools
- **health-check.php**: A clean, zero-dependency script to quickly verify PHP version, server software, HTTPS status, and critical extensions (`pdo_mysql`, `curl`, `mbstring`, etc.).
- **.htaccess**: A secure, pre-configured template to disable directory indexing and protect sensitive files.
